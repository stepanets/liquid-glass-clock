# Жидкое стекло

Виджет часов для рабочего стола Android 12 и новее. Два размера: 2×2 и 4×2. Время и дата обновляются сами, в формате телефона.

Android Studio не нужна. APK собирает GitHub Actions.

1. Открой вкладку **Actions** и дождись зелёной сборки **Build APK**.
2. Скачай артефакт `liquid-glass-clock` и установи APK на телефон.
3. Зажми свободное место на рабочем столе → **Виджеты** → **Жидкое стекло**.
